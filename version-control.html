🚀 Quick Start Guide

  1. Choose a version below - V3.0 is stable, V4.0 is for new development
  2. Click "Launch" to start the dev server (V3.0: port 3000, V4.0: port 3004)
  3. Click "Open App" to view in browser
  4. Test key features - Patti Smith reader at /paginated, Audio sync at /chapters
  5. Important: If V4.0 won't start with npm, use: npx tsx server/index.ts
