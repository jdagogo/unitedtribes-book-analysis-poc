🎯 How to Start the Application

Step 1: Navigate to Project Directory
cd ~/Desktop/my-claude/united-tribes-fresh-v4
Step 2: Verify You're on the Stable Branch
git status
Should show: "On branch v4.3.1-development"
Step 3: Start the Development Server
PORT=3004 npm run dev
Server will start on http://localhost:3004
Step 4: Open in Browser 🌐 Open http://localhost:3004

⚠️ If Something Goes Wrong

Server won't start?
1. Press Ctrl+C to stop any running servers
2. Run: lsof -ti:3004 | xargs kill -9
3. Try starting again

Wrong version running?
Run: git checkout v4.3.1-development
