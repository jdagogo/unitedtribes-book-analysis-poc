🎯 How to Start the Application

Step 1: Navigate to Project Directory
cd ~/Desktop/my-claude/united-tribes-fresh-v4
Step 2: Check Your Current Branch
git status
⚠️ IMPORTANT - You Should See One Of These:

🚧 "On branch v4.5-development" = Current development (working on new features)
🛡️ "On branch v4.4-development" = Latest stable rollback point (safe, tested)
🛡️ "On branch v4.3.2-add-pages-7-8" = Previous stable rollback point

If you see v4.3.1 or anything else:
Run: git checkout v4.5-development
Step 3: Start the Development Server
PORT=3004 npm run dev
Server will start on http://localhost:3004
Step 4: Open in Browser 🌐 Open http://localhost:3004

🛠️ Useful Commands

📊 Check YouTube API Quota Usage
node check-quota-exact.cjs
Shows exact quota usage for all 6 API keys
🗑️ Clear YouTube API Cache
rm data/youtube-api-cache.json && echo "{}" > data/youtube-api-cache.json
Clear cache to force fresh API calls (use if videos seem outdated)

⚠️ If Something Goes Wrong

Server won't start?
1. Press Ctrl+C to stop any running servers
2. Run: lsof -ti:3004 | xargs kill -9
3. Try starting again

Wrong version running?
Run: git checkout v4.3.1-development
